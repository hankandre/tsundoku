This is a fork and refactor of the booklore application now renamed to Tsundoku.

`booklore-api` is the legacy Java API. `tsundoku-api` is the new `bun` and Hono.js API. Make no updates to any application. Than `tsundoku-api`

Never use TypeScript non-null assertions. Use readable arguments and variables throughout the application, not single characters.

CRITICAL: Write clean, intuitive, and legible code that is not cognitively complex.

Use `bun --filter <package.json name> <script>` to run a script in the monorepo.

When running into issues use codesearch or websearch to resolve them rather than assuming.
